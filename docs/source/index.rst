Welcome to the SPRING module documentation!
*Spring* is a Python module for single-particle single-shot Coherent Diffraction Imaging data analysis, developed by the `NUX group <https://nux.ethz.ch/>`_.
It is designed to be **user-friendly** and to run on **interactive Python notebooks** like `Jupyter <https://jupyter.org/>`_. 
It's implementation makes an efficient use of multi-CPU and multi-GPU computing hardware.  
After the :doc:`install` step, have a look at the :doc:`quickstart` section for an easy introduction to the main features of *spring*.


Source code
^^^^^^^^^^^
